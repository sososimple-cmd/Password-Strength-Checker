# Password Strength Checker

This is a Python program that checks the strength of a password based on predefined criteria. It includes a graphical user interface (GUI) for ease of use.

## Features
- Checks for minimum length (at least 8 characters).
- Ensures the presence of uppercase and lowercase letters.
- Verifies the inclusion of numbers and special characters.
- Provides feedback on password strength (Weak, Moderate, Strong) along with a numerical score (e.g., `Weak (2/5)`).
- Includes a user-friendly GUI for testing passwords.
